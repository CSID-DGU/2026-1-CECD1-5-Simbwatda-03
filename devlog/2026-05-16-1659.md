## 5. Tier 1 시도: Gravity-snap OBB (실패 — 가정 강함)

### 5.1 가설
OBB의 most-vertical axis를 강제로 world Z에 align하면:
- mesh 자체가 upright로 회전
- axis도 같이 회전되어 (0,0,±1)로 정확히 떨어짐
- inner_box / base 동일 회전

### 5.2 구현
파일: `simulation_ready/gravity_snap.py` (신규)
- 각 part 폴더 입력
- OBB 8 corner에서 3개 edge 추출 → max |z| 인 axis 선택
- 그 axis를 (0,0,1)로 보내는 rotation R (Rodrigues formula)
- pivot = OBB centroid
- R 적용 대상: `part.ply, part.obj, base.ply, base.obj, inner_box.obj`, OBB corners, origin_world, vector_world, cuboid_world

### 5.3 백업

## 7. 다음 세션에서 할 일 — Tier 2: OVSeg3R IBSp (Phase 1a)

### 7.1 무엇을 하는가
**Inter-Boundary Separation penalty (IBSp)**: face co-occurrence graph 누적 단계에서, 같은 view 안에서 **두 face가 서로 다른 2D mask ID에 속할 때 그 edge weight를 감산 (또는 0)**. mask 경계를 가로지르는 잘못된 co-occurrence를 직접 차단 → bleeding 정점이 다른 part로 흡수되는 걸 막음.

vs Fun3DU view-weighting: Fun3DU는 view 단위 weight (좋은 view ↑, 나쁜 view ↓). IBSp는 같은 view 안에서도 mask-pair 단위 차단. **보완 관계.**

### 7.2 어디 수정
`scene2part/s2p_1_fast.py`의 edge accumulation 루프 (`s2p_1_fast.py:699-740` 부근).
현재 구조:
```python
for stem in frames:
    rasterize → triangle_id
    for mask_idx in mask_idxs:
        binary_mask = ...
        faces_idxs = triangle_id[binary_mask & valid]
        w_view = get_mask_view_weight(binary_mask)  # Fun3DU
        # 같은 mask 안의 face pair만 +w_view
        for (u,v) in pairs(faces_idxs):
            edge_count_matrix[u,v] += w_view
```

IBSp 추가 로직 (proposal):
- 같은 view에서 **다른 mask** 사이의 face pair에 negative weight (감산) 추가
- 즉 view마다: `mask_A` face 집합 × `mask_B` face 집합 cross pair에 `-w_separation` 누적
- 또는 누적 안 하고 threshold 비교 단계에서 "different-mask co-occurrence ≥ 어떤 비율"이면 제외

원본 OVSeg3R 정신:
> KNN graph edge에서 두 endpoint의 2D mask ID 다르면 edge 삭제

REACT3D에는 KNN 대신 face co-occurrence graph → "edge 삭제"를 "강한 negative weight" 또는 "post-filter"로 매핑.

## 9. 학습/메모

- **착시 주의:** `+0.998`을 0°로 읽지 말 것. `arccos(0.998) ≈ 3.6°` — 작아 보이지만 시각적으로 5도 가까이 보일 수 있음.
- **gravity-snap 같은 강한 prior는 "원인이 아닌 증상"을 가린다.** 진짜 원인은 mask bleeding이고 OBB 기울기는 그 결과. 증상 보정은 일시적이고 새 시나리오에서 깨짐.
- **REACT3D = Louvain on face co-occurrence graph (DBSCAN 아님).** IBSp 원본은 KNN graph라서 정신만 가져오고 구현은 그래프 형태에 맞게 매핑 필요.
