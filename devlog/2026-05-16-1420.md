2. normal misalignment (hidden geometry 깨짐)

### 2.4 왜 옵션 1이 안 됐나
옵션 1 (SAM image mode swap)은 모델만 SAM→SAM2로 바꾼 거. 구조는 그대로:
```
RAM++ → Qwen → GroundedDINO → SAM (per-frame, 독립) → multi-view lift → DBSCAN
                                ↓ swap만
                              SAM2 (per-frame, 독립)
```
**frame별 독립 처리 구조 자체의 문제는 model swap으로 안 풀림**. multi-view consistency 약점은 그대로.

## 4. REACT3D 파이프라인 분석 — DBSCAN 아니라 Louvain!

### 4.1 핵심 발견
`s2p_1_fast.py` 분석 결과:
```python
for frame:
    rasterize → triangle_id (각 픽셀의 mesh face)
    for mask:
        faces_in_mask = triangle_id[mask]
        for (i, j) in pairs(faces_in_mask):
            edge_count[(i,j)] += 1   ← view 모두 동일 가중치

# threshold → graph G
# Louvain community detection → cluster
```

**DBSCAN on 3D points가 아니라 face-level co-occurrence graph + Louvain community detection**.

### 4.2 IBSp / Fun3DU 정신을 REACT3D 그래프 형태로 매핑
| 정신 | DBSCAN/KNN (원본) | Louvain/co-occurrence (REACT3D) |
|---|---|---|
| **IBSp**: 2D mask 경계 = cluster 경계 | edge **삭제** | edge weight **감산** (separation count) |
| **Fun3DU**: view-quality 가중치 | top-K view 선택 | edge accumulation시 weight 곱하기 |

Phase 1b는 Fun3DU 적용 — 가장 직접적.

## 5. Fun3DU 코드 분석 + REACT3D 적용

### 5.1 Fun3DU 원본 (`/tmp/fun3du` clone)
- `utils/metrics.py:get_mask_score()`: polar coord entropy
  - `arc_score`: angular distribution이 uniform target에 KL divergence
  - `mod_score`: radial distribution이 center-concentrated target에 KL divergence
- 둘 다 entropy(p, q) = KL(p, q) 형태. 작을수록 좋음.
- Fun3DU 원본은 mask 단위 score를 filter용으로 사용 (low quality mask 제외)

### 5.2 우리 변형: weight로 사용
- `view_weight = exp(-(arc_kl + mod_kl))` ∈ (0, 1]
- high quality view → weight ≈ 1
- low quality view → weight ≈ 0
- edge_count_matrix에 weight 곱해서 누적

## 6. 첫 번째 실행 → 버그 발견

### 6.1 결과
- mesh 수: **31** (vs 옛 61, SAM2 swap 56)
- 너무 적음. **과도하게 merge**된 결과.

### 6.2 로그에서 의심스러운 부분
```
avg edge weight: 1.000, effective_threshold: 3.000
```
weight가 모두 1.0이라는 뜻? 효과가 없었다는 뜻?

### 6.3 버그 진단 (검증 스크립트 `/tmp/check_weights.py`)
200 frame * pkl mask들에 대해 `get_mask_view_weight()` 직접 호출 후 분포 확인:

**실제 per-mask weight 분포:**
- min=0.0032, max=0.7069
- **mean=0.1057, median=0.0608**
- 67% mask가 weight < 0.1
- 90% percentile = 0.26

**결론**: weight 함수는 잘 동작. weight 분포 자체는 0.1 근처에 몰림.

### 6.4 진짜 버그
`avg_w` 계산을 `edge_count_matrix.data`로 했음:
```python
nz = edge_count_matrix.data  # 누적 weight들
avg_w = nz.sum() / nz.size
weight_scale = min(1.0, avg_w)  # 클램프 1.0
```

`edge_count_matrix`는 같은 face pair가 N frame에 등장하면 weight가 N번 누적된 sparse matrix. 그래서 평균이 누적값 평균 (큰 값) → `min(1.0, ...)` 클램프에 걸려 항상 1.0.

→ **effective_threshold = 3 그대로 유지** → 실제로는 약 30 frame 등가의 매우 엄격한 threshold → 대부분 edge가 graph에 못 들어감 → 큰 community → mesh 수 31로 줄어듦.

**즉 weight는 잘 적용됐지만 threshold 조정이 잘못돼서 over-merge.**

### 6.5 fix
```python
mask_weights = np.array(
    [w for _, w in faces_idxs_per_mask if w > 0.0], dtype=np.float64
)
per_mask_avg = float(mask_weights.mean())  # raw per-mask average
weight_scale = max(0.02, per_mask_avg)  # floor 2%
effective_threshold = args.min_cooccurrence_count * weight_scale
```

이제 weight_scale ≈ 0.1 (실제 평균) → effective_threshold ≈ 0.3. 의미: "≥3 effective frames의 weighted sum".

`per-mask weight: mean=, median=, weight_scale=, effective_threshold=` 다 로깅.

## 9. 핵심 발견 / 주의사항

### 9.1 SAM2 image swap만으로는 multi-view 일관성 안 풀림
- model quality vs structural issue 구분
- frame별 독립 처리가 root cause면 model swap으로 해결 불가
- → Fun3DU/IBSp/SAM3 같은 **구조적** 변경 필요

### 9.2 mask bleeding은 두 가지 증상 동시 발생
- vertex overlap (53/71 겹침)
- normal misalignment (hidden geometry 깨짐)
- 같은 root cause → 같은 fix로 두 가지 다 해결

### 9.3 REACT3D는 Louvain on face graph
- DBSCAN이 아님
- IBSp/Fun3DU는 그래프 종류 무관하게 **정신**만 옮기면 됨
- Fun3DU: edge accumulation 시 weight 곱
- IBSp: edge weight에 separation penalty 감산

### 9.4 sparse matrix weight 합산 vs raw weight 평균
- `csr_matrix.data`는 **누적** 값 → 평균을 raw weight 평균과 혼동 금지
- raw weight는 별도 list로 추적해야 함
- 이게 첫 시도의 mesh 31개 over-merge 버그 원인

### 9.5 Fun3DU score 해석
- `arc_score`: 0 (uniform) ~ 큰 값 (한쪽 치우침). KL(hist, uniform).
- `mod_score`: 0 (center concentrated) ~ 큰 값 (edge). KL(hist, concentrated).
- 둘 다 작을수록 좋은 view.
- 우리는 `exp(-(arc + mod))`로 weight ∈ (0, 1] 만듦
- 실측: median 0.06, mean 0.10 — 대부분 view가 "썩 좋지 않다"고 판단됨 (정상; 많은 frame이 가장자리/비스듬 angle)

### 9.6 백업 디렉토리 명명

## 11. 한 줄 요약

**SAM2 swap 결과는 raw 56→articulated 12로 옛 REACT3D와 동일. 그러나 53/71 표면 겹침 등 인접 mask bleeding 문제 여전. 사용자가 normal vector 비평행도 같은 root cause임을 진단. 2026 논문 서베이 후 Fun3DU view-weighting을 Phase 1b로 채택, REACT3D의 Louvain 그래프 형태로 구현. 첫 시도는 threshold 계산 버그로 over-merge (mesh 31), 디버깅 후 per-mask raw weight 평균으로 fix. 현재 tmux `s2p_fun3du2`에서 재실행 중.**
